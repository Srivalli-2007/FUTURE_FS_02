# 🚀 Client Lead Management System (Mini CRM)

A responsive and user-friendly **Client Lead Management System (Mini CRM)** developed using **HTML, CSS, and JavaScript**. This application helps businesses manage leads generated through contact forms by tracking lead details, updating statuses, maintaining notes, and monitoring conversions.

---

## 📌 Project Overview

This project was developed as part of an internship task to demonstrate understanding of:

- CRUD Operations
- Lead Management Workflow
- Frontend Development
- Data Storage using Local Storage
- Dashboard Analytics
- Responsive Web Design

The CRM acts as a centralized platform where administrators can store, manage, and monitor customer leads efficiently.

---

## 🎯 Problem Statement

When visitors submit inquiries through a website contact form, businesses need a system to:

- Store lead information
- Track lead progress
- Manage follow-ups
- Convert leads into customers

This Mini CRM solves that problem by providing an easy-to-use dashboard for lead management.
